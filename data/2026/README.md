# data/2026

2026 年の福岡市長選のポスター掲示場のデータ。

## boards.csv

選挙管理委員会が決めた掲示場の一覧。`pnpm import:boards` で取り込む。

## board-areas.csv

掲示場ごとの小学校区と町名（1,824 か所）。カバー地域の画面で、校区・町名ごとに数えるために使う。

列は `number,school,school_source,town,chome`。`number` は boards.csv の番号と同じ。

- `school`: 小学校区（例: 馬出小）。
- `school_source`: 校区の決まり方。`pdf` か `map`。
- `town`: 町名。`大字` で始まる町名は、その後ろの「字…」と「無番地」を落とした（例: `大字玄界島字浜ノ上` は `大字玄界島`）。
- `chome`: 丁目の数字だけ（例: `1`）。丁目のない町名は空。

### 出典

福岡市教育委員会「通学区域一覧表（学校別）令和8年4月1日現在」
https://www.city.fukuoka.lg.jp/kyoiku-iinkai/tsuugaku/ed/area/documents/R8gakkoubetu.pdf
（2026-10-27 取得）

### 決まり方の内訳

- `pdf` 1,797 か所: 掲示場の住所（町名・丁目・番・号）を通学区域一覧表に当てて、校区が 1 つに決まったもの。
- `map` 27 か所: 住所を一覧表に当てても 1 つに決まらなかったもの（校区が複数の候補に分かれた・一覧表に町名がない・
  候補が 1 校だけで条件に合わなかった、など）。
  候補の校区（一覧表で住所に当たった校区。なければ空）の中から、緯度経度の簡易な平面距離でいちばん近い `pdf` の掲示場を選び、その校区を取った。
  候補が空のときは、`pdf` の掲示場の中でいちばん近いものの校区を取った。

### 掲示場が増えたとき

選管の変更で掲示場が増えたら、この表にも同じ番号の行を足す。足さないと、`pnpm import:boards` は
「校区・町名の表にない番号」と出して取り込みを止める（`--dry-run` でも同じ）。
